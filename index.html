I've been making Rain World mods for a long time. I write only code, not art/sprites. If you have a slugcat, mechanic, or creature idea I'm able to build it.

What I take

  • Slugcat abilities and movement (SlugBase or from scratch)
  • Gameplay mechanics, stamina, hydration, items, HUD stuff, Remix config menus, whatever code related
  • Creature behaviour and AI changes, new creatures if you have the art
  • Fixing or porting mods that broke on Watcher / newer versions

Not taking: regions, art, sprites, sound. If your project needs those I can probably recommend you someone.

Pricing

Before I start anything you get a written quote with an hours estimate. I will notify you before I hit my estimate if I should stop at the estimate or keep going and you will be given a new estimate. Changes to the plan after we agree on it get added separately.

Rough idea of what things cost:

Fix / port a broken modusually 1-4 hrs $50+
Single mechanic (stamina, a new item, HUD element)3-10 hrs, $100+
Slugcat ability kit (several abilities + config)15-40 hrs, split into milestones $250+
Creature behaviour / new creature10-40 hrs depending on what it does and usually around $400+

These are guesses and change massively depending on the feature.

How it works

  1. DM me on Discord (mills888) with what you want. Doesn't need to be polished, I'll ask questions. A design doc helps a lot but isn't required.
  2. I send a quote. Bigger stuff gets broken into milestones, each with its own price.
  3. New clients pay 50% of the milestone up front and rest if they want to test. Returning clients pay 50% to test.
  4. I build it and send you a DLL to test in your own game. You tell me what's off, I fix it.
  5. When you're happy, you pay the rest and get the source code for the project.
